🚀 Projeyi Çalıştırma Komutları
1. Python Bağımlılıklarını Yükle
bash
cd ai_yemekhane
pip install -r requirements.txt
2. .env Dosyası Oluştur
Proje dizininde (c:\Users\cemil\Desktop\AI-Smart-Cafeteria-Waste-Reduction/ai_yemekhane/) bir .env dosyası oluşturun:

env
GEMINI_API_KEY=buraya-gemini-api-keyinizi-yazin
ADMIN_PASSWORD=admin123
SECRET_KEY=dev-secret-key-degistir
DEBUG=True
PORT=8001
3. Veritabanını Hazırla (İlk Kurulum)
bash
cd ai_yemekhane
python scripts/data/load_menu_data.py
python scripts/data/seed_data.py
4. Sunucuyu Başlat
bash
cd ai_yemekhane
python main.py
Açılınca: http://localhost:8001

5. Sayfalar
Sayfa	Adres

6. Testleri Çalıştır
bash
cd ai_yemekhane
pytest tests/ -v
7. Mobil Uygulama (Opsiyonel)
bash
cd ai_yemekhane/mobile_app
npm install
npm run start
